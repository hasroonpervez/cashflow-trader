# Thin desk

SvelteKit 5 page that loads snapshot bars from the Litestar API at /api/bars/{symbol}.
It does not fetch market data itself.

After a JS package install in this directory, run the Vite dev script (loopback 5173).
The API must already be serving on 127.0.0.1:8000. See docs/PHASE_B_DESK.md.
